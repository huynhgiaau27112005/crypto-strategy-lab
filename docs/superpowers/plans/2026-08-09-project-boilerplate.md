# Project Boilerplate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scaffold `service/` (NestJS modular monolith with 11 module stubs), `web-platform/` (Vite + React + TS page stubs), `docs/prototype/` (clickable HTML UI), plus root README and `.gitignore`.

**Architecture:** Flat monorepo folders; one NestJS deployable with domain modules under `src/modules/`; React SPA for future UI; static HTML prototype for stakeholder approval before React port.

**Tech Stack:** NestJS + TypeScript, Vite + React + TypeScript + React Router, static HTML/CSS/JS, npm.

## Global Constraints

- Package manager: npm only
- Folder name: `service` (singular), not `services`
- Modular monolithic — no microservices, no Turborepo/pnpm workspace
- No business logic, DB, Binance, queue, or chart libraries
- Do not commit unless the user explicitly asks (user rule overrides frequent-commit steps)
- Spec: `docs/superpowers/specs/2026-08-09-project-boilerplate-design.md`

## File Structure

| Path | Responsibility |
|------|----------------|
| `service/` | NestJS app generated by CLI |

### Task 2: Add 11 Nest module stubs

**Files:**
- Create: `service/src/modules/<name>/{<name>.module.ts,<name>.controller.ts,<name>.service.ts,index.ts}` for each of:
  - `market-data`, `chart`, `strategy-engine`, `strategy-plugin`, `composite-strategy`, `strategy-search`, `backtesting`, `leaderboard`, `continuous-loop`, `news`, `sentiment`
- Modify: `service/src/app.module.ts`

**Interfaces:**
- Consumes: NestJS `Module`, `Controller`, `Injectable` from `@nestjs/common`
- Produces: each controller exposes `GET /<kebab-route>/health` returning `{ status: 'ok', module: '<name>' }`

Route map (controller path → module folder):

| Path | Class prefix |
|------|----------------|
| `market-data` | `MarketData` |
| `chart` | `Chart` |
| `strategy-engine` | `StrategyEngine` |
| `strategy-plugin` | `StrategyPlugin` |
| `composite-strategy` | `CompositeStrategy` |
| `strategy-search` | `StrategySearch` |
| `backtesting` | `Backtesting` |
| `leaderboard` | `Leaderboard` |
| `continuous-loop` | `ContinuousLoop` |
| `news` | `News` |
| `sentiment` | `Sentiment` |

- [ ] **Step 1: Create all 11 modules** using this pattern (example `market-data`):

`service/src/modules/market-data/market-data.service.ts`:

```typescript
import { Injectable } from '@nestjs/common';

@Injectable()
export class MarketDataService {}
```

`service/src/modules/market-data/market-data.controller.ts`:

```typescript
import { Controller, Get } from '@nestjs/common';
import { MarketDataService } from './market-data.service';

@Controller('market-data')
export class MarketDataController {
  constructor(private readonly marketDataService: MarketDataService) {}

  @Get('health')
  health() {
    return { status: 'ok', module: 'market-data' };
  }
}
```

`service/src/modules/market-data/market-data.module.ts`:

```typescript
import { Module } from '@nestjs/common';
import { MarketDataController } from './market-data.controller';
import { MarketDataService } from './market-data.service';

@Module({
  controllers: [MarketDataController],
  providers: [MarketDataService],
  exports: [MarketDataService],
})
export class MarketDataModule {}
```

`service/src/modules/market-data/index.ts`:

```typescript
export * from './market-data.module';
export * from './market-data.service';
```

Repeat for all 11 with matching names/paths.

Replace `service/src/app.module.ts` imports so it imports all 11 modules. Remove default `AppController`/`AppService` only if Nest scaffold leftovers conflict; prefer keeping Nest default health at `/` if present, plus domain modules.
